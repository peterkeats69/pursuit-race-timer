# Pursuit Race Timer — GitHub Pages

Upload all four app files (`index.html`, `manifest.webmanifest`, `service-worker.js`, `icon.svg`) to the root of a public GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)** and Save. Open the published `https://USERNAME.github.io/REPOSITORY/` URL on your tablet. Use the browser menu to install/add to home screen.

Set the first start time, race duration and fleet offsets; save and back up settings. Arm the race in advance, test speech and volume, keep the screen awake and the app foregrounded. The browser speech engine is not guaranteed to announce each second precisely; electronic hoots and countdowns are not substitutes for official timekeeping and physical signals. Offline operation works after a successful first online load and service-worker installation.
